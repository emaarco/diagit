# Glossary

**Notation** — a kind of diagram the extension can render, identified by its file extensions
(BPMN, DMN, Wardley Map, Team Topologies, Event Storming, Context Map, Value Chain).
_Avoid_: kind, diagram type, model type.

**Git host** — a site that serves repository files, such as github.com, gitlab.com or a
self-hosted GitLab / GitHub Enterprise instance.

**Blob page** — a git host's page that shows a single file of a repository.

**Diff** — the added, removed, changed and moved elements between the old and the new version
of a diagram in a pull request, merge request or commit. Only some notations have one.

**View** — what the extension shows the user: the blob viewer, the diff viewer, the standalone
viewer or the options page.
